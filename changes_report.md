## 3. Публикация версий на сервере (Деплой)
Публикация версий калькулятора Stout & Rommer на живом сервере производится по следующему принципу:

1. **Хостинг:** Приложение развернуто на бесплатном хостинге статических сайтов **GitHub Pages** (проект привязан к домену `terem24.github.io` и настроен на работу через CNAME-файл с адресом `heatcalc.ru`).
2. **Процесс деплоя:** Вся публикация происходит автоматически при отправке изменений (командой `git push`) из локального репозитория на GitHub в ветку `main`.
3. **Роль ИИ-помощника:** Ассистент работает исключительно в вашей локальной папке на компьютере (`c:\Users\d.ibatullin\Yandex.Disk\!Работа\...`). Ассистент **никогда самостоятельно не публикует код на сервер** (не выполняет `git push`) и не имеет доступа к секретам GitHub.
4. **Последняя опубликованная версия:** Версия, запущенная на живом сервере `heatcalc.ru`, полностью определяется тем, какой последний коммит вы отправили в GitHub со своего компьютера. Если вы выполните `git push` прямо сейчас, на сервере опубликуется абсолютно чистая версия `af97774` (от 11:02 сегодняшнего дня), так как все экспериментальные изменения стёрты.
