# Отчёт о работе и отмене изменений (HeatCalc.ru)

В данном отчёте зафиксирована хронология изменений, внесённых в файлы калькулятора `app.js` и `index.html` в ходе текущего сеанса, а также детали произведённого отката к исходному рабочему состоянию.

---

## 1. Внесённые изменения (до отката)

До выполнения отката в рабочей копии были реализованы следующие технические решения:

### А. Отопление и Тёплый пол (ТП)
* **Индивидуальный шаг укладки**: Из верстки `index.html` и логики `app.js` удалены общие переключатели режима ТП («Быстрый» / «Подробный») и глобальный выбор шага. Добавлены независимые селекторы шага укладки трубы (`100`, `150`, `200` мм) отдельно для каждого этажа (отображались под ползунками площадей ТП в режиме «Подробный»).
* **Физический расчёт трубы**: Длина трубы рассчитывалась по точной формуле:
  $$L = \left(\frac{S}{h}\right) \times 1.1$$
  где $S$ — площадь зоны, $h$ — шаг укладки (в метрах), $1.1$ — коэффициент запаса на изгибы.
* **Подбор петель и коллекторов**: Количество контуров ТП рассчитывалось как $N = \lceil L / 80 \rceil$ без принудительного ограничения минимального числа петель до двух. Коллекторы подбирались строго по полученному числу выходов.

### Б. Водоснабжение и бойлер ГВС
* **Разбавление воды**: Учтён физический коэффициент смешивания $60^\circ\text{C}$ воды из бойлера с холодной водой $10^\circ\text{C}$ для получения комфортной температуры $40^\circ\text{C}$ (коэффициент разбавления `0.6` от общего пикового объема).
* **Коэффициент одновременности**: Внедрён расчет коэффициента одновременного использования ($k_{одн}$) по СП 30.13330.2020:
  * 1-2 прибора — $k_{одн} = 0.7$
  * 3 прибора — $k_{одн} = 0.5$
  * 4 и более приборов — $k_{одн} = 0.4$
* **Приоритет расчёта**: Выбор объема бойлера по точкам водоразбора ( fixtures ) при включенном водоснабжении стал приоритетным по отношению к выбору по количеству жильцов.
* **Подсказки**: Детализировано описание подбора бойлера по кнопке `i`.

### В. Изменения пользовательского интерфейса (UI)
* **Интерфейс замены товаров**: Из текстового описания позиций в таблице сметы удален обработчик клика для вызова окна замены. Замена товара («Нажмите, чтобы заменить») вызывалась теперь только при клике непосредственно на изображение товара.
* **Удаление позиций**: Иконка `🗑` в смете заменена на красный крестик `✖` со стилизованной подсказкой при наведении: *"Удалить позицию"*.
