# План публикации HeatCalc в Google Play и RuStore

## Обзор

| | Google Play | RuStore |
|---|---|---|
| Стоимость регистрации | **$25** (~2300₽) разово | **Бесплатно** |
| Срок проверки приложения | 1–7 дней | 1–3 дня |
| Аудитория | Весь мир | Россия |
| Формат | AAB (Android App Bundle) | APK или AAB |

**Общий бюджет:** ~2300₽ + время  
**Общий срок:** ~2 недели

---

## Этап 1 — Регистрация аккаунтов
**Срок: День 1–2**

### Google Play Console
1. Зайти на [play.google.com/console](https://play.google.com/console)
2. Зарегистрироваться как разработчик — оплатить **$25** картой (нужна нероссийская карта — Visa/MC выпущенная за рубежом, или виртуальная карта)
3. Заполнить профиль разработчика

> ⚠️ **Важно про оплату Google:** российские карты не принимаются. Нужна карта Казахстана, Армении, или сервис типа YooMoney/Wise.

### RuStore Console
1. Зайти на [console.rustore.ru](https://console.rustore.ru)
2. Регистрация через Gosuslugi или вручную (паспорт + ИНН)
3. Физлицо подходит — ИП не обязательно
4. **Бесплатно**

## Этап 2 — Подготовка графики и текстов
**Срок: День 2–3**

### Что нужно создать

| Материал | Размер | Где используется |
|---|---|---|
| Иконка приложения | 512×512 PNG | Оба магазина |
| Feature Graphic (шапка) | 1024×500 PNG | Google Play |
| Скриншоты телефона | мин. 2 шт, 1080×1920 | Оба магазина |
| Краткое описание | до 80 символов | Оба магазина |
| Полное описание | до 4000 символов | Оба магазина |
| Политика конфиденциальности | страница на сайте | **Обязательно** для обоих |

### Скриншоты
Открыть `heatcalc.ru` в Chrome на телефоне → сделать скриншоты главных экранов: расчёт, смета, каталог.

### Политика конфиденциальности
Обязательное требование обоих магазинов — нужна страница `heatcalc.ru/privacy.html` с описанием что собирается (email, Supabase).

## Этап 3 — Техническая сборка APK
**Срок: День 3–4**

Используем **PWABuilder** — бесплатный инструмент Microsoft для PWA→Android.

### Шаг 3.1 — Генерация проекта
1. Открыть [pwabuilder.com](https://www.pwabuilder.com)
2. Ввести `https://heatcalc.ru` → Start
3. Выбрать **Android** → **Generate Package**
4. Настроить:
   - Package ID: `ru.heatcalc.app`
   - App name: `HeatCalc`
   - Версия: `1.0`
5. Скачать ZIP — внутри готовый Android-проект

### Шаг 3.2 — Сборка AAB
Нужен **Android Studio** (бесплатно, ~1.2 ГБ):
1. Открыть скачанный проект
2. Build → Generate Signed Bundle → AAB
3. Создать keystore-файл (ключ подписи — **хранить вечно!**)

### Шаг 3.3 — Файл assetlinks.json
Техническая связка домена и приложения. Без него TWA не работает.

Разместить на сайте по адресу:
```
https://heatcalc.ru/.well-known/assetlinks.json
```

Содержимое генерирует PWABuilder автоматически — кладём файл в репозиторий GitHub.

## Этап 4 — Публикация
**Срок: День 5**

### Google Play
1. Play Console → Создать приложение
2. Заполнить описание, загрузить скриншоты и иконки
3. Загрузить AAB файл
4. Указать ссылку на политику конфиденциальности
5. Отправить на проверку

### RuStore
1. console.rustore.ru → Добавить приложение
2. Заполнить описание, загрузить графику
3. Загрузить APK или AAB
4. Отправить на проверку

---

## Этап 5 — Ожидание проверки
**Срок: 1–7 дней**

- Google Play: 1–7 дней (первая публикация дольше)
- RuStore: 1–3 рабочих дня
